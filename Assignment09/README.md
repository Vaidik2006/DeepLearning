# Assignment 9: Image Classification using Pretrained Vision Transformer and CNN

## Objective
Fine-tune a pretrained Vision Transformer (ViT) for image classification and compare it with a CNN baseline using accuracy, macro precision, macro recall, macro F1-score, inference time, and confusion matrices.

## Dataset and models
- Dataset: CIFAR-10 (10 image classes).
- ViT: `google/vit-base-patch16-224-in21k`, pretrained and fine-tuned on CIFAR-10.
- CNN: compact custom CNN trained from scratch on the same selected train/test examples.

The notebook uses a reproducible subset by default to keep an initial Google Colab run practical. Increase `MAX_TRAIN`, `MAX_TEST`, and `EPOCHS` for a more comprehensive experiment. Actual metrics are generated by running the notebook; this repository does not invent performance numbers.

## Google Colab
1. Open `notebooks/Assignment_09_ViT_CNN_Comparison.ipynb` in Google Colab.
2. Select Runtime → Change runtime type → GPU (T4 if available).
3. Run all cells from top to bottom. The notebook installs dependencies, downloads CIFAR-10 and pretrained ViT weights, trains both models, evaluates them, plots confusion matrices, and downloads a ZIP of results.

## Local run
Python 3.10 or 3.11 recommended:
```bash
pip install -r requirements.txt
python train_compare.py --epochs 3 --batch-size 32 --max-train 10000 --max-test 2000
```
GPU is strongly recommended for ViT fine-tuning.

## Evaluation
- Accuracy
- Macro precision, recall, and F1-score
- Inference time per image
- Confusion matrix and per-class classification report

The comparison is between transfer learning with a pretrained ViT and a CNN trained from scratch, so initialization and architecture both differ.
