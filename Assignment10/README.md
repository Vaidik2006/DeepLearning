# Assignment 10: Audio Classification with Speech-to-Text and Text-to-Speech

A deep-learning application that classifies environmental audio and also provides speech-to-text (STT) and text-to-speech (TTS) features through a Streamlit interface.

## Features

- **Audio classification:** a custom CNN classifies audio into the 50 environmental sound categories in ESC-50.
- **Speech-to-text:** a pretrained Whisper Tiny model transcribes speech from an uploaded audio recording.
- **Text-to-speech:** a pretrained Facebook MMS-TTS English model generates speech from entered text.
- **Evaluation:** reports test accuracy, macro precision, macro recall, macro F1-score, a classification report, and a confusion-matrix image.
- **Local web interface:** upload audio, inspect the predicted class, transcribe speech, and generate speech from text.

> Important: the CNN must be trained on ESC-50 before the classification feature can run. The first run of STT/TTS downloads pretrained models from Hugging Face. No API key is required. Model downloads require internet access; inference runs locally after the models are downloaded.

## Architecture

### 1. Audio classification CNN

1. Read an audio clip and resample it to 16 kHz mono.
2. Convert the waveform into a log-Mel spectrogram with 64 Mel bands.
3. Feed the spectrogram to a convolutional neural network (CNN).
4. Use global average pooling and a fully connected layer to predict one of 50 classes.

```text
Audio waveform
      │
      ▼
Resample to 16 kHz, mono
      │
      ▼
Log-Mel spectrogram (64 Mel bands)
      │
      ▼
CNN: Conv → BatchNorm → ReLU → Pool (repeated)
      │
      ▼
Global average pooling → Fully connected layer
      │
      ▼
Predicted environmental sound class
```

### 2. Speech features

- **STT:** `openai/whisper-tiny` through Hugging Face Transformers.
- **TTS:** `facebook/mms-tts-eng` through Hugging Face Transformers.

These are pretrained deep-learning models. They are separate from the CNN trained for environmental sound classification.

## Dataset

This project uses the **ESC-50** environmental sound dataset. It contains 2,000 five-second recordings across 50 classes, with five predefined folds. The training script uses folds 1–3 for training, fold 4 for validation, and fold 5 for testing.

The dataset is downloaded by `download_dataset.py` from the public ESC-50 GitHub repository. Dataset files are not included in this repository.

## Setup

Python 3.10 or 3.11 is recommended.

### 1. Create and activate a virtual environment

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

For PyTorch, if the default installation does not match your computer, use the official selector at https://pytorch.org/get-started/locally/.

### 3. Download the dataset

```bash
python download_dataset.py
```

This creates `data/ESC-50/` and downloads the dataset. Internet access is required for this step.

### 4. Train the classifier

```bash
python train.py --epochs 20 --batch-size 16
```

The best validation model is saved as `models/audio_cnn.pt`; the class names are saved to `models/classes.json`. Training may take a while, especially on CPU.

### 5. Evaluate on the held-out test fold

```bash
python evaluate.py
```

Metrics and the confusion matrix are written to `results/`. **Use the values generated by your run in your report; no performance results are fabricated or prefilled.**

### 6. Launch the application

```bash
streamlit run app.py
```

Open the local URL printed in the terminal by Streamlit. The first STT/TTS use downloads the pretrained model weights. The application accepts common audio formats supported by FFmpeg/libsndfile; WAV is the safest format.

## Evaluation metrics

- **Accuracy:** fraction of test clips classified correctly.
- **Precision (macro):** average precision across classes, treating each class equally.
- **Recall (macro):** average recall across classes.
- **F1-score (macro):** harmonic mean of precision and recall, averaged equally across classes.
- **Confusion matrix:** shows which classes are confused with one another.
- **Word Error Rate (WER):** a suitable metric for STT if reference transcripts are available. WER is not reported automatically because ESC-50 is an environmental-sound dataset and does not provide spoken reference transcripts for these clips.

## Notes and limitations

- ESC-50 focuses on environmental sounds, not speech transcription. Use a separate speech recording for the STT tab.
- Whisper and MMS-TTS are pretrained models; this project uses them for inference rather than training them from scratch.
- Predictions depend on audio quality, the dataset split, random initialization, and training settings.
- Do not commit datasets, model checkpoints, virtual environments, or caches to GitHub.
- If your faculty expects speech-command classification rather than environmental sound classification, the dataset and labels should be changed to a speech-command dataset.
